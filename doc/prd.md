# Product Requirements Document (PRD) – Plot

## 1. Overview

**Plot** is a web-based storytelling workspace designed to help writers transform raw ideas into structured, emotionally rich narratives. It enables users to organize themes, characters, conflicts, and scenes while attaching resources for deeper storytelling.

---

## 2. Objectives

* Provide a structured workflow for story creation
* Enable transition from messy drafts to polished stories
* Enhance storytelling using resources and visual references
* Build a scalable platform for writers and creators

---

## 3. Target Users

* Students and beginner writers
* Content creators (YouTube, short films, etc.)
* Scriptwriters and storytellers

---

## 4. Core Features

---

### 4.1 Unified Story Overview (New Combined Screen)

A single structured screen that combines:

* Story Basic Info (Title, Theme, Description)
* Conflict Builder
* World Setting
* Resource Attachments

#### Sections inside Overview:

##### 🟢 Basic Info

* Title (input)
* Theme (input)
* Description (textarea)

---

##### 🔴 Conflict Builder (Enhanced)

* Add **Conflict Title**
* Conflict Type (Internal / External / Society)
* Detailed Description (textarea)

**Features:**

* ➕ Add multiple conflicts using "Add Conflict" button
* Each conflict is stored as a separate block
* Each conflict supports:

  * Resource attachment (links, notes, references)

---

##### 🌍 World Setting

* Time (input)

* Location (input)

* Atmosphere (textarea)

* Environment Description

* Attach:

  * Images
  * Notes
  * References

---

##### 📎 Resources Section

* Add global story resources:

  * URL
  * Notes
  * Media
* Link resources to:

  * Conflict
  * World
  * Scenes

---

---

### 4.2 Character Management (Enhanced)

#### Character Creation

* ➕ “Add Character” button
* Characters displayed in card/grid format

---

#### Character Input Structure

##### 🟢 Basic Info

* Name (input)
* Role Type (Main / Sub-main / Supporting / Antagonist)
* Short Description (textarea)

---

##### 🎯 Motivation

* Goal (input)
* Fear (input)
* Desire (input)

---

##### ⚔️ Traits

* Strengths (tag input)
* Weakness (tag input)
* Personality (tag input)

---

##### 🔥 Conflict (Character Level)

* Internal Conflict (textarea)
* External Conflict (textarea)

---

##### 🔗 Relationships

* Select another character
* Relationship type (friend, rival, mentor, enemy)
* Short description

---

##### 📈 Character Arc

* Starting State (input)
* Ending State (input)

---

##### 📎 Resources (New)

* Attach references specific to character:

  * Notes
  * URLs
  * Inspiration

---

### 4.3 Scene Builder (Enhanced)

#### Scene Management

* ➕ “Add Scene” button
* Scenes displayed as collapsible cards
* Scene ordering with:

  * Up / Down buttons (reordering)

---

#### Scene Input Structure

##### 🟢 Basic Info

* Scene Title (input)
* Scene Type (dropdown: Introduction, Conflict, Climax, Resolution)
* POV Character (select from Character Management)

---

##### 🎯 Scene Goal

* Purpose of the scene (textarea)

---

##### 🌍 Setting

* Location (input)
* Time (input)
* Environment / Mood (textarea)

---

##### 👥 Characters in Scene

* Multi-select characters from Character Management
* Assign role (lead, support, antagonist)

---

##### 🎬 Action / Events

* Main events (textarea)
* Turning point (input)

---

##### ⚔️ Conflict (Scene Level)

* Internal conflict (textarea)
* External conflict (textarea)

---

##### 🎭 Dialogue System (Enhanced)

* ➕ Add Dialogue button

Each dialogue row includes:

* Character selector (from Character Management)
* Dialogue input field

---

##### 🧱 Background / Situation Description

* Separate textarea for:

  * Scene context
  * Background details

---

##### 🔄 Outcome

* What changes after this scene (textarea)
* Impact on story

---

##### 📎 Scene Resources (New)

* Attach:

  * References
  * Notes
  * Visual inspiration

---

### 4.4 Writing Mode

* Clean, distraction-free editor
* Convert structured story → narrative format
* Use scene data + dialogue + character context

---

## 5. Success Metrics

* User engagement (stories created per user)
* Scene completion rate
* Retention rate
* Time spent in writing mode

---

## 6. Future Scope

* AI-assisted writing
* AI character and scene generation
* AI image generation
* Export to screenplay / PDF
* Collaboration features

---

## ✅ Final Outcome

Plot becomes a **structured storytelling system** where:

* Overview = story foundation
* Characters = emotional drivers
* Scenes = execution layer
* Resources = depth and realism

Enabling users to move from:
**Idea → Structure → Scene → Story → Final Output**
